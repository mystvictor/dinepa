# Offre Technique DINEPA — Numerech

Prototype web de présentation de l'offre technique.

## Fichiers

- `index.html` — structure et contenu
- `styles.css` — design responsive, impression A4 et mode sombre
- `app.js` — navigation active, progression, retour en haut, impression et thème

## Utilisation

Le bouton « Imprimer / PDF » utilise la boîte d'impression native du navigateur.
Pour un rendu PDF propre, sélectionner « Enregistrer au format PDF ».
